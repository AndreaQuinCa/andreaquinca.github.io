# Andrea Quintanilla — academic website

A small, responsive, static website for GitHub Pages. It uses plain HTML and CSS, so it needs no build step or dependencies.

## Pages

- `index.html` — home and short research profile
- `research.html` — research areas and selected papers
- `teaching-experience.html` — teaching, professional experience and education
- `talks-posters.html` — talks and posters
- `miscellanea.html` — training, award and personal interests

## Publish with GitHub Pages

1. Create a GitHub repository for the site. For a user site, name it `AndreaQuinCa.github.io`; for a project site, any repository name works.
2. Upload the files in this folder to the repository root, preserving the `assets` folder.
3. In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will show the published address in the same settings page after deployment.

The photo is included in `assets/andrea-quintanilla.jpg`. Update the contact and profile links in the HTML if needed.
